客户端

02 / CLIENTS

客户端只负责连接与配置，不改变订阅额度。以下按常见平台分组说明界面位置； 各客户端版本迭代较快，若菜单名称与描述不同，以你本机实际界面为准。

桌面端 · Desktop

Windows / macOS

安装后从订阅页复制配置，粘贴到客户端的订阅导入位置即可。桌面端通常支持托盘常驻与开机启动。

  1. 打开客户端，进入「配置」或「订阅」面板。
  2. 粘贴订阅链接，执行导入并等待列表刷新。
  3. 在节点列表中选择一条线路，再开启系统代理。
  4. 连接后在客户端首页核对当前线路与流量统计。

移动端 · Mobile

iOS / Android

移动端在导入订阅后需要授权本地代理权限，首次连接时系统会弹出确认提示，属正常流程。

  1. 在应用内找到「添加订阅」并粘贴链接。
  2. 允许应用添加本地代理配置。
  3. 选择线路后点击连接，状态栏出现标识即生效。
  4. 切换网络（如从 Wi-Fi 到蜂窝）后建议重新选择一次线路。

网络设备 · Router

路由器与共享环境

在路由器上配置时，整个局域网共用同一个订阅账号，因此需要按「同时在线设备」上限评估是否够用。

  1. 确认路由器固件支持手动填写代理或订阅地址。
  2. 在管理后台填写订阅信息并保存。
  3. 逐台设备验证出口是否一致。
  4. 团队版可按需申请定制路由说明。

使用说明

03 / HOW TO

从选择档位到完成一次连接，一共四步。每一步都可以独立回退，不涉及不可撤销的操作。

对照表格选档位

先看流量额度与同时在线设备数这两行，它们决定了日常使用的上限；再看支持渠道是否符合你的沟通习惯。

确定计费周期

月付与年付对应同一档位配置，差异只在结算周期与总额。年付金额在表格第二行单独标出，便于直接换算。

导入订阅

在客户端中粘贴订阅链接并刷新节点列表。若列表为空，先检查链接是否完整复制，再检查客户端时间是否正确。

核对状态

连接后确认当前线路名称与剩余流量显示。数字与所选档位不一致时，先退出重进，再联系对应支持渠道。

常见问题

04 / FAQ

以下问题按提问频率排列，左栏偏方案与计费，右栏偏客户端与日常使用。

Q1三个档位的差别主要集中在哪些行？

集中在流量额度、同时在线设备数、线路类型与支持渠道四行。价格随这四行同步变化，其余行多为附加项，例如团队版的定制路由。

Q2年付比月付便宜多少？

按表格数字直接换算：基础版年付 ¥150 相当于 10 个月月付金额，旗舰版年付 ¥350 同样为 10 个月，团队版年付 ¥850 亦然。具体以购买页显示为准。

Q3“同时在线设备”是怎么计算的？

指同一时刻保持连接状态的设备数量。关闭客户端或断开连接后即释放名额。在路由器上配置时，整个局域网按共享同一账号计算。

Q4当月流量用完了会怎样？

额度按自然月计。页面不承诺额外的补偿机制，也不描述超出后的处理细节；如需了解，请通过对应档位的支持渠道确认。

Q5可以在多个平台同时使用同一账号吗？

可以，前提是不超过该档位的设备数上限。桌面端、移动端与路由器共用同一份名额，因此建议先统计常连设备再选档位。

Q6导入订阅后节点列表是空的，先查什么？

依次检查三项：订阅链接是否被截断、客户端与订阅是否在同一网络环境、设备系统时间是否准确。多数空白列表由链接不完整或时间偏差导致。

Q7换设备或重装系统后需要重新购买吗？

不需要重新选择档位。在新设备上重新导入同一份订阅即可，只要同时在线的设备数不超出所选档位上限。

Q8团队版的定制路由需要准备什么信息？

至少需要说明使用场景、需要区分的网段或设备范围，以及预计同时在线的终端数量。这些信息由专属客户经理对接收集。

Q9页面上写的线路优化，能保证游戏延迟吗？

不能。表格描述的是线路类型与优化方向，实际延迟受本地网络、运营商与国际链路共同影响，页面不作数值承诺。

Q10价格或配置调整后，这个页面会同步吗？

页面内容是对外说明的一部分，配置变化时应保持与购买页一致。若发现两处不一致，请以购买页标注为准，并通过支持渠道反馈。
